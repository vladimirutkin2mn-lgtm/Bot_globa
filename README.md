# Bot_globa — персональный AI-оракул

Telegram-first продукт, который создаёт персонализированные мистические разборы как развлекательный и рефлексивный опыт.

Первый MVP включает четыре направления:

1. таролог;
2. любовный оракул;
3. мистический психолог;
4. персональный гороскоп / астролог.

Пользователь выбирает направление, задаёт вопрос и получает интерактивный разбор. Продукт помнит предыдущие обращения, связывает новые ответы со старой историей и может формировать безопасные карточки для публикации.

Для таро карты выбирает детерминированный Symbolic Engine. Для гороскопа отдельный Astrology Calculation Engine рассчитывает натальную карту по дате, времени и месту рождения; LLM только объясняет рассчитанные данные и не придумывает положения планет.

> Продукт не выдаёт предсказания за достоверные факты, не гарантирует события будущего и не заменяет медицинскую, юридическую, финансовую или психологическую помощь.

## Техническая основа

В качестве исходной платформы выбран проект `ideas/ai-relationship-platform` из репозитория `fabric_bot`. В нём уже реализованы Telegram-интерфейс, PostgreSQL, LLM-оркестрация, структурированные ответы, история разборов, шифрование чувствительных данных, платные кредиты, разовые покупки, подписки, возвраты, фоновые задачи, аналитика, Docker и CI.

Переносить предлагается именно этот подпроект с сохранением git-истории через `git subtree split`, а затем последовательно заменить relationship-domain на `Reading`/`Persona`/`Memory`/`Symbolic Engine`/`Astrology Calculation Engine`.

## Первый технический шаг

Отдельным pull request перенести неизменённый HeartSignal baseline в `Bot_globa`, добиться зелёного CI и только после этого начинать продуктовую переделку. Это позволит сохранить работающие платежи, privacy-механики и release gates и не смешивать перенос с изменением поведения.
