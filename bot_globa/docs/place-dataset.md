# Справочник мест рождения

Астролог ищет место рождения по файлу внутри сервиса, а не через внешний API.

## Почему файл

Геокодер вызывается **один раз на пользователя** — когда он вводит место рождения. Не на
каждый разбор. Платный тариф OpenCage начинается с $50/месяц за 10 000 запросов в сутки:
это оплата мощности, которая не понадобится ещё очень долго. Бесплатный тариф там же явно
запрещает продакшен.

Второй довод весомее денег. Место рождения — чувствительные данные: они шифруются при
хранении и закрыты согласием. Внешний геокодер означал, что этот единственный факт мы
всё-таки кому-то отправляем, и экран согласия обязан был честно об этом предупреждать.
С файлом предупреждать не о чем.

Побочные следствия: поиск не может отвалиться по таймауту, упереться в лимит или лечь
вместе с вендором.

Плата за это — данные являются снимком и обновляются вручную, и поиск сопоставляет
названия, а не угадывает опечатки.

## Что внутри

`app/providers/geocoding/data/places.tsv.gz` — 69 607 городов от 5 000 жителей, 1.8 МиБ.
Шесть колонок:

```
label \t latitude \t longitude \t timezone \t population \t aliases
```

`label` — готовая подпись вида «Тюмень, Россия», русская где GeoNames знает русское
название. `timezone` — IANA-зона, та самая, ради которой обычно и платят геокодеру.
`aliases` — нормализованные варианты написания через `|`, по ним идёт поиск: регистр,
лишние пробелы и «ё» уже свёрнуты.

Поиск: точное совпадение псевдонима, затем совпадение по префиксу; внутри каждой группы
выше стоит город с большим населением — при одинаковых названиях место рождения почти
наверняка крупнее.

## Как обновить

```bash
cd /tmp && for f in cities5000 alternateNamesV2; do
  curl -O https://download.geonames.org/export/dump/$f.zip && unzip -oq $f.zip
done
curl -O https://download.geonames.org/export/dump/countryInfo.txt
```

```bash
python scripts/build_place_dataset.py /tmp
```

Скрипт пишет результат детерминированно (`mtime=0`, сортировка по geonameid), поэтому
перегенерация из того же дампа даёт побайтово тот же файл — в ревью попадут только
настоящие изменения данных.

Обновлять имеет смысл раз в год-полтора: города редко переименовывают, а часовые пояса
меняются чаще, чем кажется.

## Лицензия и атрибуция

Данные: [GeoNames](https://www.geonames.org/), лицензия
[CC BY 4.0](https://creativecommons.org/licenses/by/4.0/). Лицензия требует указания
авторства — эта страница и есть указание; при публикации справочника отдельно от сервиса
атрибуцию нужно сохранить.

## Другие провайдеры

`GEOCODING_PROVIDER` принимает три значения:

| Значение | Когда |
|---|---|
| `offline` | по умолчанию и в продакшене |
| `opencage` | если понадобится живой поиск с опечатками; требует ключ и **возврата предупреждения в текст согласия** |
| `stub` | 44 города для локальной разработки; в продакшене запрещён `validate_production_providers` |
