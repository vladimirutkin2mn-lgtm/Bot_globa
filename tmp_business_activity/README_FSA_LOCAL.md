# Росаккредитация: локальный прогон первых 1 000 ИНН

Пакет проверяет первые 1 000 компаний из нашего исследования в публичных реестрах Росаккредитации:

- сертификаты: `rss/certificate`;
- декларации: `rds/declaration`;
- отдельно определяет роль компании: `MANUFACTURER`, `APPLICANT`, `IMPORTER`;
- считает действующие и исторические документы;
- сохраняет продукцию и ссылки на evidence;
- сетевой блок/403/timeout записывает как `SOURCE_UNAVAILABLE`, а не как `NOT_FOUND`.

## Windows

1. Установить Python 3.11 или 3.12, если его ещё нет.
2. Распаковать ZIP в отдельную папку.
3. Дважды кликнуть `run_fsa_windows.bat`.

Либо из PowerShell:

```powershell
py -m pip install -r requirements_fsa.txt
py enrich_fsa_1000.py
```

## macOS / Linux

```bash
python3 -m pip install -r requirements_fsa.txt
python3 enrich_fsa_1000.py
```

## Результаты

После завершения появится папка `output_fsa_1000`:

- `fsa_1000.csv` — одна строка на ИНН;
- `fsa_1000_raw.json` — все найденные документы и detail-карточки в нормализованном виде;
- `summary.json` — сводка по прогону.

Ключевые поля CSV:

- `ФСА статус`;
- `ФСА сертификаты`;
- `ФСА декларации`;
- `ФСА действующие`;
- `ФСА manufacturer`;
- `ФСА applicant`;
- `ФСА importer`;
- `ФСА продукция`;
- `ФСА evidence URLs`.

## Если Росаккредитация не открывается

Если весь файл получает `SOURCE_UNAVAILABLE`, значит `pub.fsa.gov.ru` недоступен с вашего текущего IP. Сам код при этом работает корректно.

При наличии разрешённого proxy можно задать переменную окружения `FSA_PROXY_URL`.

PowerShell:

```powershell
$env:FSA_PROXY_URL="http://user:password@host:port"
py enrich_fsa_1000.py
```

Также поддерживаются `FSA_TOKEN` и `FSA_COOKIE`, если у вас есть легитимные данные сессии/доступа.

## Важно

Отсутствие документов в ФСА само по себе не означает, что компания не ведёт реальную деятельность. Для нашего скоринга наличие документа — positive evidence; отсутствие используется только с учётом применимости реестра к деятельности компании.
